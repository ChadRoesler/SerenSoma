Set up the robot

Everything that makes this robot yours: its Wi-Fi, the voice server it checks in with (this box, unless you say otherwise), the token its control API asks for, and a tailnet if you use one. Leave a box empty to leave that alone. A robot on the network takes these straight away and reboots; one that isn't yet (a new one, or one whose Wi-Fi changed) gets them from a soma.yaml on its microSD card, which it reads once at boot and deletes. No Wi-Fi password is kept here.

Token

The robot takes it first, then this box writes it down, then the robot reboots onto it. If the robot says no, nothing changes. A Workbench or Psycheion pointed at the same token file picks it up by itself.

Firmware

Fetch a release (checked against its SHA256SUMS) or stage a build of your own (stack-chan.bin), then install it: the robot is offered it once, on its next check-in, shows its progress, and reboots into it. If the new one can't check in, it goes back to the old one on the next reboot.
